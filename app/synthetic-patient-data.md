## **Section 2: Trial-Matching Schema**

### **2.1 Persona record fields**

| Field | Type | Description |
| :---- | :---- | :---- |
| persona\_id | string | Unique ID, format P-\#\#\# |
| name | string | Fictional full name |
| age | integer | Age in years |
| sex | enum | Sex as stated |
| location | string | Fictional town and state |
| occupation / living\_situation | string | Work setting and household |
| current\_situation | text | Stressor that precipitated or maintains symptoms |
| symptom\_profile | list | Symptom descriptors, tagged by domain |
| gad7 / phq9 | integer | Total scores (GAD-7 0 to 21; PHQ-9 0 to 27\) |
| symptom\_duration\_months | number | Time since symptom onset |
| prior\_treatment | list | Type, sessions or dose, outcome, and stop date |
| current\_medications | list | Name, dose, start date, and whether it is an antidepressant, benzodiazepine, or sedative |
| substance\_use | enum | None, occasional, or active use disorder |
| suicidality | enum | None, past (over 12 months), or current |
| flags | list | Items for screening staff to verify |

### **2.2 Inclusion criteria (reference trial)**

| ID | Criterion |
| :---- | :---- |
| I-1 | Age 18 to 65 inclusive |
| I-2 | GAD-7 score 10 to 14 (moderate range) |
| I-3 | PHQ-9 score below 15 |
| I-4 | Symptom duration at least 3 months |
| I-5 | Able to attend in-person or telehealth visits |
| I-6 | Provides informed consent as an adult |

### **2.3 Exclusion criteria**

| ID | Criterion |
| :---- | :---- |
| E-1 | Current SSRI or SNRI, or any antidepressant within 4 weeks (washout) |
| E-2 | Benzodiazepine or sedative-hypnotic use, including OTC sleep aids |
| E-3 | Current suicidality, or suicidal behavior within 12 months |
| E-4 | Active substance use disorder within 6 months |
| E-5 | Bereavement within 6 months |
| E-6 | Enrollment in another GAD trial within 12 months |
| E-7 | Bipolar, psychotic, or primary panic disorder (requires screening) |

## **Section 3: Match Score Rationale**

Each persona is scored against the reference trial above. Scores total 100 across six components. Eligibility is set by the hard gates (I-1, I-2, I-3, and the E-criteria), and the score ranks eligible candidates. "Verify" means a screening check is still open.

### **3.1 Scoring weights**

| Component | Max | Scoring rule |
| :---- | :---- | :---- |
| Severity fit | 30 | GAD-7 10 to 14: 30\. GAD-7 8 to 9 or 15 to 16: 15\. Other values: 5\. |
| Age eligibility | 15 | 18 to 65: 15\. Outside range: 5\. |
| Medication compatibility | 20 | No interacting medication: 20\. Polypharmacy or chronic-condition check: 15\. Sedative or washout to verify: 10\. Concurrent antidepressant: 0\. |
| Prior treatment | 10 | None: 10\. Prior therapy or app: 7\. Discontinued medication: 5\. |
| Logistics and consent | 15 | Standard (including remote): 15\. Schedule, caregiver, coverage, or consent barrier: 10\. |
| Depression ceiling and safety | 10 | PHQ-9 under 10: 10\. PHQ-9 10 to 14: 7\. PHQ-9 15 or above: 0\. |
